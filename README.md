# Ανάλυση και Αυτόματη Θεματική Κατηγοριοποίηση Hashtags

## Περιγραφή

Η παρούσα πτυχιακή εργασία αφορά την ανάλυση και την αυτόματη θεματική κατηγοριοποίηση hashtags σε δεδομένα κοινωνικών δικτύων, με χρήση τεχνικών Μηχανικής και Βαθιάς Μάθησης.

Χρησιμοποιήθηκε σύνολο δεδομένων 732 αναρτήσεων. Τα hashtags υποβλήθηκαν σε διαδικασία εξαγωγής, κανονικοποίησης και θεματικής ομαδοποίησης, με αποτέλεσμα τη δημιουργία οκτώ τελικών θεματικών κατηγοριών.

Για κάθε ανάρτηση προσδιορίστηκε μία κύρια θεματική κατηγορία, η οποία χρησιμοποιήθηκε ως μεταβλητή-στόχος για την εκπαίδευση των μοντέλων ταξινόμησης.

## Στόχος

Στόχος της εργασίας ήταν η διερεύνηση της δυνατότητας αυτόματης πρόβλεψης της κύριας θεματικής κατηγορίας μιας ανάρτησης και η σύγκριση διαφορετικών προσεγγίσεων Μηχανικής και Βαθιάς Μάθησης.

## Μοντέλα

Υλοποιήθηκαν και συγκρίθηκαν τα ακόλουθα μοντέλα:

- Random Forest
- k-Nearest Neighbors (kNN)
- Support Vector Machine (SVM)
- LSTM
- Bi-LSTM
- Bi-LSTM2
- Bi-LSTM Hybrid
- Bi-LSTM Numeric + Text

## Χαρακτηριστικά

Στα μοντέλα χρησιμοποιήθηκαν διαφορετικές ομάδες χαρακτηριστικών, όπως:

- Likes
- Retweets
- αριθμός hashtags
- πλατφόρμα
- sentiment
- κειμενική πληροφορία

## Αξιολόγηση

Η αξιολόγηση των μοντέλων πραγματοποιήθηκε με τις μετρικές:

- Accuracy
- Precision
- Recall
- F1-score
- Macro F1-score
- Weighted F1-score

Χρησιμοποιήθηκαν επίσης πίνακες σύγχυσης (Confusion Matrices) για την αναλυτικότερη εξέταση των προβλέψεων ανά κατηγορία.

## Αποτελέσματα

Τα μοντέλα που βασίστηκαν αποκλειστικά σε αριθμητικά χαρακτηριστικά παρουσίασαν περιορισμένη απόδοση.

Η ενσωμάτωση περισσότερων χαρακτηριστικών και, κυρίως, της κειμενικής πληροφορίας οδήγησε σε σημαντική βελτίωση της απόδοσης.

Το Bi-LSTM Numeric + Text παρουσίασε την υψηλότερη Accuracy, με τιμή 63,95%.

## Περιορισμοί

Βασικοί περιορισμοί της μελέτης είναι:

- το σχετικά μικρό μέγεθος του συνόλου δεδομένων,
- η ανισορροπία μεταξύ των κατηγοριών,
- η απουσία ξεχωριστού validation set,
- η πιθανότητα υπερπροσαρμογής του τελικού μοντέλου.
